O código gerado foi esse:

const board = new PrimeiroLanceBoard({
    element: "board",
    fen: "start",
    draggable: true
});

Basicamente é criada uma constant chamada Board, onde é geradi/incializado o tabuleiro do chessboard.js

O element = "board" indica aonde será criado o tabuleiro, ou seja, dentro de uma div de id = board

<div id = board> tabuleiro </div>

O fen é o que define a posição das peças, no caso o "start" indica a posição inicial.

E o draggable é o que define se o tabuleiro está no modo interativo ou não, nesse caso como está "true" o usuario pode interagir com ele.
Se não quiser isso é só usar o "false" que ele deixará de ser interativo (ficara estatico)
